# R1 上层主控 — 长记忆匣

## 1. 项目概述

- **MCU**: STM32F407VET6, 自制A板
- **RTOS**: FreeRTOS, 6个任务, 全部优先级0
- **遥控器**: 乐迪T16D, 16通道, 独立SBUS接收机 (UART4)
- **CAN**: CAN1=抬升+抓取+YV, CAN2=机械臂
- **IR**: USART1/2/3/6 DMA, CH7切换触发
- **结构**: 模块化 — main.c(调度+锁车+消抖) + lift.c + arm.c + grab.c

## 4. 状态机

### 抬升 (lift.c)
```
CH6/CH12/CH10 → lift_update(目标值) → 硬限幅 → 自适应斜率 → 50Hz pos_ctrl
斜率: 差值>3.0用快步进(2.5), ≤3.0用慢步进(0.5)
硬限幅: LIFT_MIN(0.2) ~ LIFT_MAX(29.0)
```

### 机械臂 (arm.c) — 短臂
```
每臂独立: ARM_UP ↔ ARM_DOWN
CH12中/下 + CH13选臂 + CH15回弹 → 切换
  UP(吸): root=±1.57, tip=±0.785 (45°朝天)
  UP(放): root=±1.57, tip=±1.57 (朝前)
  DOWN:  root=0, tip=0° (朝前)
arm_task clampf限幅后发送, 速度分离(UP/DOWN)
tick间隔>50ms自动CH15同步
```

### 抓取 (grab.c)
```
G_IDLE(0) → … → G_FLIP_BACK(5) → G_LIFT_RISE(6) → G_FLIP_GRAB(7)
CH12上+CH15回弹推进(0→5→6→7)
步骤6: 翻转=0°, CH6全局三档控高度, CH10增量微调
步骤7: 三态循环(0→-0.4→-1.0→0), CH6 + CH10微调
CH8: 旋钮绝对映射齿条 0~15
4340: MIT模式 KP30/KD5, 硬限幅0~-2.0
2325: POS模式, 硬限幅0~15
齿条归零(RACK_ZERO_TOL 0.2)才开夹爪
```

### 吸盘 (main.c)
```
臂打下 + 可触发 → 吸盘锁存(ON), CH11前推关左/后拉关右
臂抬起不关, 方块不掉
放方块仅最低档(0.0)触发, 吸方块全楼层触发
```

### IR (main.c)
```
CH7每次切换 → USART1/2/3/6 DMA发送 A1F1CC01EE (无条件)
```

## 5. 安全机制

- SBUS帧校验 + DMA NDTR陈帧检测 + 100ms断联
- failsafe标志 → 立刻锁车
- 锁车后每200ms重发disable确保电机收到
- CH12模式消抖50ms
- 抬升自适应斜率+硬限幅
- 机械臂/翻转/齿条硬限幅
- 跨模式CH15/CH1 tick间隔防抖(>50ms自动同步)
- CH4边沿锁车(不重置last_ch4)
