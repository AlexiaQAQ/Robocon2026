# R1 上层主控 — 长记忆匣

## 1. 项目概述

- **MCU**: STM32F407VET6, 自制A板
- **RTOS**: FreeRTOS, 6个任务, 全部优先级0
- **CAN**: CAN1=抬升+抓取+YV, CAN2=机械臂
- **SBUS**: UART4 DMA循环, 独立接收机
- **IR**: USART3+USART6 DMA发送, CH4中位+CH7边沿触发
- **结构**: 模块化 — main.c(调度+锁车+消抖) + lift.c + arm.c + grab.c

## 3. 状态机

### 抬升 (lift.c)
```
CH5中位/下拨/上拨 → lift_update(目标值) → 硬限幅 → 自适应斜率 → 50Hz pos_ctrl
斜率: 差值>3.0用快步进(2.5), ≤3.0用慢步进(0.5)
硬限幅: LIFT_MIN(0.2) ~ LIFT_MAX(29.0)
```

### 机械臂 (arm.c) — 短臂
```
每臂独立: ARM_UP ↔ ARM_DOWN
CH5中位/下拨 + CH11选臂 + CH7边沿 → 切换
  UP:   root=±1.57, tip=±0.785 (45°朝天)
  DOWN: root=0, tip=±0.785 (朝前)
arm_task clampf限幅后发送
tick间隔>50ms自动CH7同步 (防跨模式误触发)
```

### 抓取 (grab.c)
```
G_IDLE(0) → G_RACK_ZERO(1) → G_CLAW_OPEN(2) → G_FLIP_DOWN(3)
→ G_CLAW_CLOSE(4) → G_FLIP_BACK(5) → G_LIFT_RISE(6)
CH5上拨+CH7边沿推进(0→5→6停止)
步骤6: CH7切换翻转(0↔-0.4), CH6全局三档控抬升
CH10始终控制齿条, CH1增量微调中/高档(±3.0)
4310: 翻下6.0/翻上2.0, 硬限幅0~-2.0
```

### 模式调度 (main.c)
```
CH4中位: 独占IR串口模式 (CH7→USART3+USART6)
CH4下拨/上拨+CH5: 50ms消抖后确认模式
  ├─ CH5上拨 → 抓取
  ├─ CH5中位 → 吸方块 (CH6选层高+CH1微调+臂)
  └─ CH5下拨 → 放方块 (CH6双档+CH1微调+臂)
全局: CH8/CH9吸盘, CH10齿条
```

## 5. 安全机制

- SBUS帧校验: buf[0]==0x0F && buf[24]==0x00
- DMA NDTR陈帧检测: 连续5次不变→丢弃
- 100ms断联 → 自动锁车(不重置last_ch4)
- failsafe标志 → 立刻锁车
- CH5模式消抖50ms
- 抬升自适应斜率+硬限幅
- 机械臂/翻转硬限幅
- 跨模式CH7/CH1 tick间隔防抖(>50ms自动同步)
- 齿条归零才开夹爪(RACK_ZERO_TOL 0.2)
