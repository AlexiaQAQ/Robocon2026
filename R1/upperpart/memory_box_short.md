# R1 上层主控固件 — 短记忆匣

## 项目
STM32F407VET6 + FreeRTOS，**自制 A 板**（与 R2 同款）。SBUS 遥控控制（独立接收机，与下层无线路连接），Keil MDK-ARM 工程。

## 当前状态 (2026-06-15 底盘解耦后)

| 子系统 | 状态 | 说明 |
|--------|------|------|
| SBUS 遥控 | ✅ | UART4 DMA, 帧校验, 50ms 超时断联 |
| CH4 锁车 | ✅ | 3 段拨杆上拨解锁 (>1300)，下拨锁车 (<650) |
| LED 流水灯 | ✅ | GPIOE[0:7], 解锁 200ms / 锁车 100ms |
| 底盘控制 | ❌ 已移除 | 移交给下层 Robomaster A 板 |
| 机械臂 IK | ⚠️ 待恢复 | arm.c/h 保留在 Lib，待重新接入 |
| 夹取机构 | ⚠️ 待恢复 | grabbing.c/h 保留在 Lib，待重新接入 |
| 电磁阀 | ⚠️ 待恢复 | solenoid_valves.c/h 保留在 Lib |

## 关键参数

| 参数 | 值 |
|------|-----|
| MCU | STM32F407VET6, 168MHz |
| SBUS | UART4 (PA0/PA1), 100kbps, 9-bit Even 2-stop |
| CH4 解锁阈值 | `>1300` (3 段拨杆) |
| CH4 锁车阈值 | `<650` |
| SBUS 超时 | 50ms |
| 所有任务优先级 | 0，时间片轮询 |

## 遥控器通道量程

| 通道 | 控件 | 量程 |
|------|------|------|
| CH0~CH3 | 摇杆 | 326~1659 (中位 992) |
| CH4~CH6 | 3 段拨杆 | 326 / 992 / 1659 |
| CH7 | 2 段拨杆 | 329 / 1659 |
| CH8~CH11 | 旋钮 | 326~1659 |

> 上下层各有独立接收机，绑定同一遥控器。

## FreeRTOS 任务

| 任务 | 周期 | 栈 | 说明 |
|------|------|-----|------|
| start_task | 一次性 | 256 | 初始化 SBUS，创建子任务后自销毁 |
| sbus_task | 10ms | 512 | SBUS 解码 + 断联保护 + CH4 锁车 |
| led_task | 100/200ms | 128 | GPIOE 流水灯 |

## 已知问题

1. **pid.h 类型重定义** — `int8_t`/`uint8_t` 与 `<stdint.h>` 可能冲突
2. **YV9/YV10 flip bug** — `solenoid_valves.h` 异或操作写错数组下标
3. **旧文件残留** — `*_ik.o`, `upstairs.o` 为旧版本编译残留
