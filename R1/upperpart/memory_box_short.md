# R1 上层主控 — 短记忆匣

## 项目
STM32F407VET6 + FreeRTOS, 自制A板。抬升 + 短双臂 + 抓取(4340MIT) + 4路IR。乐迪T16D 16通道独立SBUS。

## 当前状态

| 模块 | 文件 | 功能 |
|------|------|------|
| SBUS | sbus_set.c | DMA循环 + NDTR陈帧检测 + failsafe |
| 抬升 | lift.c | 4×DM4340, 自适应斜率, 硬限幅, YV_flash |
| 机械臂 | arm.c | 4×DM (短臂), CH15切换, 竖起45°朝前 |
| 抓取 | grab.c | 4340(MIT)+2325, 7步工序, CH6三档, CH7三态循环 |
| IR | main→UART | CH7切换→USART1/2/3/6 DMA |
| 吸盘 | main→锁存 | 臂打下→吸, CH11前推关左/后拉关右 |
| 锁车 | main.c | CH4两档, CH12消抖50ms, 断联100ms, failsafe |

## 任务 (全部prio=0)

| 任务 | 周期 |
|------|------|
| sbus_task | ~4ms |
| lift_task | 50Hz |
| arm_task | 50Hz |
| grab_task | 50Hz |
| led_task | 100/200ms |

## 遥控器 (乐迪T16D, 物理↔SBUS反相: 上拨=ch_low<650)

| CH | 控件 | 功能 |
|----|------|------|
| 1 | 摇杆 | 中/下:连续微调, 上:增量微调 |
| 4 | 2段 | 下拨=解锁, 上拨=锁车+清抓取 |
| 5 | 2段 | 未用 |
| 6 | 3段 | 抓取:上25/中14.2(对接)/下0.2, 吸:上28/中18/下8, 放:上20/下0 |
| 7 | 2段 | IR触发 (每次切换) |
| 8-9 | 旋钮 | 未用 |
| 10 | 回中旋钮 | 齿条:前推伸出/后拉缩回 |
| 11 | 回中旋钮 | 前推关左吸盘/后拉关右吸盘 |
| 12 | 3段 | 模式切换:上=抓取, 中=吸方块, 下=放方块 (50ms消抖) |
| 13 | 2段 | 下拨=左臂, 上拨=右臂 |
| 14 | 3段 | 未用 |
| 15 | 回弹 | 工序推进/臂切换/翻转循环 (松手触发) |
