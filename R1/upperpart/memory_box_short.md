# R1 上层主控 — 短记忆匣

## 项目
STM32F407VET6 + FreeRTOS, 自制A板。抬升平台 + 短双机械臂 + 抓取机构 + 双IR。独立SBUS接收机。

## 当前状态

| 模块 | 文件 | 功能 |
|------|------|------|
| SBUS | sbus_set.c | DMA循环 + NDTR陈帧检测 + failsafe |
| 抬升 | lift.c | 4×DM4340, 自适应斜率, 硬限幅, YV_flash |
| 机械臂 | arm.c | 4×DM (短臂), CH7切换, 竖起45°朝前 |
| 抓取 | grab.c | 2×(4310+2325), 6步工序, CH6三档, CH7翻转, YV3 |
| IR | main→UART | CH4中位+CH7→USART3+USART6 DMA发送 |
| 吸盘 | main→solenoid | CH8→YV1, CH9→YV2 (全局) |
| 锁车 | main.c | CH4边沿, CH5消抖50ms, 100ms断联, failsafe |

## 任务 (全部prio=0)

| 任务 | 周期 |
|------|------|
| sbus_task | ~4ms |
| lift_task | 50Hz |
| arm_task | 50Hz |
| grab_task | 50Hz |
| led_task | 100/200ms |

## 遥控器 (物理↔SBUS反相)

| CH | 控件 | 功能 |
|----|------|------|
| 1 | 摇杆 | 中/下:连续微调, 上:增量微调 |
| 4 | 3段 | 中=IR, 下=解锁, 上=锁车+清抓取 |
| 5 | 3段 | 上=抓取, 中=吸方块, 下=放方块 (50ms消抖) |
| 6 | 3段 | 抓取:上25/中14.15(对接)/下0.2, 吸:上24/中14/下4, 放:上16.5/下0 |
| 7 | 2段 | 中/下:臂切换, 上:工序推进/翻转切换 |
| 8,9 | 旋钮 | 吸盘 YV1/YV2 |
| 10 | 旋钮 | 齿条 0~12 (全局) |
| 11 | 旋钮 | >1000左臂, <1000右臂 |
