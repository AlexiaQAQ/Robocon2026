# R1 上层主控 — 短记忆匣

## 项目
STM32F407VET6 + FreeRTOS, 自制A板。抬升平台 + 双机械臂 + 抓取机构 + 吸盘。独立SBUS接收机, 与下层无线路连接。

## 当前状态

| 模块 | 文件 | 功能 |
|------|------|------|
| SBUS | sbus_set.c | DMA循环 + 帧头尾校验 + failsafe检测 |
| 抬升 | lift.c | 4×DM4340, 回零/高度(CH6), 50Hz, YV_flash |
| 机械臂 | arm.c | 4×DM(4340+4310), UP/DOWN状态机, CH11选臂+CH7切换 |
| 抓取 | grab.c | 2×(4310+2325), 8步工序+6↔7循环切换对接/初始高度, YV3 |
| 吸盘 | main→solenoid | CH8→YV1, CH9→YV2 |
| 锁车 | main.c | CH4边沿, 100ms断联, failsafe立刻锁 |

## 任务 (全部prio=0)

| 任务 | 周期 |
|------|------|
| sbus_task | ~4ms |
| lift_task | 50Hz |
| arm_task | 50Hz |
| grab_task | 50Hz |
| led_task | 100/200ms |

## 遥控器 (物理↔SBUS反相)

| CH | 控件 | 功能 |
|----|------|------|
| 4 | 3段 | 中/下=解锁, 上=锁车, 中位清抓取 |
| 5 | 3段 | 上=抓取, 中=抬升+臂 |
| 6 | 3段 | 抬升高度 / 3层标志 |
| 7 | 2段 | 臂切换 / 抓取工序推进 |
| 8,9 | 旋钮 | 吸盘 YV1/YV2 |
| 10 | 旋钮 | 齿条 0~12 |
| 11 | 旋钮 | >1000左臂, <1000右臂 |
