## 概述

**🏆 全国大学生机器人大赛 Robocon 2026 — 国家一等奖**

本项目为 R1 机器人**上层**主控制板固件，基于 **STM32F407VET6** (Cortex-M4F, 168MHz) + **FreeRTOS** 实时操作系统开发。

> 🛠️ **硬件开源**: 自制 A 板原理图 & PCB → [立创开源链接](https://oshwhub.com/alexia0/project_krimgbaw)

> **硬件平台**: 自制 A 板（与 R2 主控相同），非 Robomaster 开发板 A 型。R1 下层底盘使用 Robomaster 开发板 A 型（STM32F427IIHx）。上下层各有独立 SBUS 接收机，无线路连接。

R1 上层负责：4×DM4340 抬升平台、左右双机械臂（2×2 关节）、抓取机构（齿条+翻转+夹爪）、吸盘电磁阀。与下层底盘共享遥控器，各自独立解析 SBUS。

> **2026-07-04**: 🏆 全国一等奖 — 所有功能稳定运行至比赛结束

## 硬件架构

### 主控芯片
- **MCU**: STM32F407VET6 (Cortex-M4F, 168MHz, 512KB Flash, 192KB SRAM)
- **硬件板**: 自制 A 板（与 R2 主控相同）
- **时钟**: HSE 12MHz → PLL 168MHz

| 外设 | 引脚 | 用途 |

| CAN1 | PD0/PD1 | 抬升×4 + 抓取×2 + YV 电磁阀刷新 (CAN ID 0x300) |
| CAN2 | PB5/PB6 | 双机械臂 DM 电机 ×4 |
| UART4 | PA0(TX)/PA1(RX) | SBUS 遥控器 (100kbps, 9E2, DMA 循环) |

| SPI1/2/3 | — | MCP2515 预留 |
| USART1 | PA9/PA10 | 调试串口 (115200-8N1) |
| KEY1 | PB2 | 按键输入 |

## 软件架构

### 目录结构

```
R1/upperpart/
├── Core/Src/main.c              # 主程序: 锁车 + SBUS调度 + 任务创建
├── Lib/
│   ├── sbus_set.c/h             # SBUS DMA循环接收 + 帧解析
│   ├── dm_motor.c/h             # 达妙电机 CAN 驱动库
│   ├── lift.c/h                 # 抬升模块 (状态机 + 50Hz控制)
│   ├── arm.c/h                  # 双机械臂模块 (UP/DOWN状态机 + 限幅)
│   ├── grab.c/h                 # 抓取模块 (6步工序状态机)
│   ├── solenoid_valves.c/h      # 电磁阀 YV1~YV10
│   ├── bsp_can.c/h              # CAN 滤波器
│   ├── can_receive.c/h          # CAN 接收回调
│   ├── mcp2515.c/h              # MCP2515 SPI-CAN
│   └── pid.c/h                  # PID (预留)
├── Doc/                         # 文档
├── Drivers/ / Middlewares/      # HAL + FreeRTOS
└── MDK-ARM/                     # Keil 工程
```

### FreeRTOS 任务

| 任务 | 周期 | 栈 | 优先级 | 功能 |
|------|------|-----|--------|------|
| `start_task` | 一次性 | 256 | 0 | 初始化 → 建子任务 → 自销毁 |
| `sbus_task` | ~4ms | 512 | 0 | sbus_poll + 锁车 + 模式调度 |
| `led_task` | 100/200ms | 56 | 0 | LED 流水灯 |
| `lift_task` | 50Hz | 512 | 0 | 抬升 4×pos_ctrl + YV_flash |
| `arm_task` | 50Hz | 256 | 0 | 双机械臂 4×pos_ctrl + 限幅 |
| `grab_task` | 50Hz | 256 | 0 | 抓取 2×pos_ctrl |

## 遥控通道分配

> 物理拨杆与 SBUS 反相: 物理上拨 → ch_low(<650), 物理下拨 → ch_high(>1300)

| 通道 | 控件 | 功能 |
|------|------|------|
| CH1 | 摇杆 | 吸/放:连续微调 (中位死区±20) |
| CH4 | 2段拨杆 | 下拨=解锁, 上拨=锁车+清抓取 |
| CH6 | 3段拨杆 | 抓/吸/放 各模式独立三档高度 (见下表) |
| CH7 | 2段拨杆 | IR触发 (每次切换→USART1/2/3/6 DMA) |
| CH8 | 旋钮(面板) | 齿条绝对映射 0~15 |
| CH10 | 回中旋钮 | 抓取模式增量微调对接高度 (±0.05/次, 累积±3.0) |
| CH11 | 回中旋钮 | 前推关左吸盘/后拉关右吸盘 |
| CH12 | 3段拨杆 | 模式: 上=抓取, 中=吸方块, 下=放方块 (50ms消抖) |
| CH13 | 2段拨杆 | 下拨=左臂, 上拨=右臂 |
| CH15 | 回弹拨杆 | 工序推进/臂切换/翻转循环 (松手触发) |

### 锁车/解锁

- CH4 两档: 下拨→解锁, 上拨→锁车+清抓取 (边沿触发)
- 100ms 断联 → 自动锁车
- failsafe → 立刻锁车
- 锁车后每200ms重发disable确保电机收到

## 机械臂 (短臂)

| 关节 | ID | 范围 | 说明 |
|------|-----|------|------|
| 左根 | 1 | 0~-1.57 | 0=水平, -1.57=竖起 |
| 左末 | 2 | 0~-1.57 | 0=顺臂朝前, -0.785=45°, -1.57=朝前(放方块) |
| 右根 | 3 | 0~1.57 | 0=水平, 1.57=竖起 |
| 右末 | 4 | 0~1.57 | 0=顺臂朝前, 0.785=45°, 1.57=朝前(放方块) |

- 默认: 竖起 (root=±1.57, tip=±0.785/45°)
- CH15 切换选中臂(松手触发), CH13 选臂
- 吸方块: 放下末端0°朝前, 抬起45°
- 放方块: 放下末端0°朝前, 抬起±1.57朝前
- ARM_SPEED_UP/DOWN 独立调速
- arm_task 每帧 clampf 限幅

### 吸盘

- 臂打下 + 可触发 → 吸盘锁存 ON
- CH11前推关左/后拉关右 (手动释放)
- 臂抬起不关, 方块不掉
- 放方块仅最低档(0.0)触发, 中/高档不触发
- 吸方块全楼层触发

## 抓取工序

CH12上拨 + CH15松手推进 0→5→6→7:

| 步 | 状态 | 翻转位置 | 说明 |
|----|------|---------|------|
| 0 | 空闲 | 0 | 夹爪关 |
| 1 | 齿条回零 | 0 | 夹爪关 |
| 2 | 开夹爪 | — | YV3(1), 齿条归零才开 |
| 3 | 翻转取杆 | -1.8 | MIT |
| 4 | 关夹爪 | — | YV3(0) |
| 5 | 翻回 | 0 | |
| 6 | 对接/回零 | 0 | CH6全局三档控高度 |
| 7 | 三态循环 | 0→-0.4→-1.0 | 每次CH15松手切换 |

- 4340: MIT模式 KP30/KD5, 硬限幅 0~-2.0
- 2325: CH8绝对旋钮 0~15, POS模式
- CH6 三档: 上拨25.0 / 中位14.2(对接) / 下拨0.2(回零)
- CH10 增量微调对接高度 (±0.05/次, 累积±3.0)

## 安全机制

1. **SBUS**: 帧校验 + DMA NDTR陈帧检测 + 100ms断联 + failsafe立刻锁车
2. **锁车重发**: 每200ms重发disable确保电机收到
3. **CH12 模式消抖** (50ms): 路过中间档不触发
4. **抬升**: 自适应斜率+硬限幅(0.2~29.0)
5. **机械臂**: arm_task 每帧 clampf, 速度分离
6. **翻转**: 硬限幅 0~-2.0 (MIT)
7. **齿条**: 硬限幅 0~15, 按电机速度步进
8. **跨模式防抖**: CH15/CH1 tick间隔>50ms自动同步
9. **齿条归零锁**: 齿条≤0.2才开夹爪
